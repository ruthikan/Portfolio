PolySum AI – Multilingual Hybrid Text Summarization Platform

Welcome to my advanced NLP project, PolySum AI, a transformer-based multilingual hybrid text summarization system designed to generate accurate, fluent, and configurable summaries across multiple languages. This project demonstrates my expertise in Natural Language Processing, deep learning, and end-to-end system deployment by combining extractive and abstractive summarization techniques into a production-ready web application.

What I’ve Implemented:

  • Hybrid Summarization Pipeline: TextRank (extractive) + Transformer Models (mT5/mBART)
  • Multilingual Processing: Automatic language detection and cross-lingual summarization
  • Configurable Inference Modes: Fast, Balanced, and Quality modes for performance tuning
  • Evaluation Metrics: ROUGE-1 (0.58), ROUGE-2 (0.41), ROUGE-L (0.55), ROUGE-Lsum (0.56)
  • Optional LLM Refinement: Integration with Gemini API for improved fluency and readability
  • Data Handling: Text preprocessing, noise removal, and intelligent segmentation

Project Highlights:

  • Hybrid NLP Architecture: Combined extractive and abstractive techniques to improve summary coherence and factual accuracy.
  • Multilingual Capability: Supported multiple languages including English, Hindi, and Telugu with consistent performance.
  • High Performance: Achieved strong ROUGE scores, indicating effective content coverage and coherence.
  • Web Application Deployment: Built a Flask-based interface for real-time summarization and user interaction.
  • Summary History Tracking: Stored outputs using SQLite for reproducibility and analysis.
  • Scalable Design: Modular architecture enabling future integration with additional models and datasets.

Tools & Technologies Used:

  • Python, Flask (Web Deployment)
  • Transformers (mT5, mBART), Hugging Face
  • NumPy, Pandas (Data Processing)
  • NLTK / TextRank (Extractive Summarization)
  • SQLite (Database for history tracking)
  • LoRA / QLoRA (Parameter-efficient fine-tuning concepts)
